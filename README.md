# TOPSIS Analysis for Pre-Trained Text Classification Models

## Overview of Approach

**Data Acquisition**  
Collection of textual datasets for evaluation purposes

**Model Evaluation**  
Performance assessment across multiple pre-trained models

**Metric Computation**  
Determination of accuracy alongside additional performance indicators

**TOPSIS Score Generation**  
Application of TOPSIS methodology to derive final rankings

## Key Specifications

- **Weight Assignment**: Must be non-negative values (strictly > 0)
- **Impact Direction**: Can be designated as Positive (+) or Negative (-)
- **Deliverables**: Tabular results and visual representations

## Project Goals

- Implementation of fundamental mathematical operations for TOPSIS score computation
- Identification of optimal pre-trained model for text classification tasks
- Exploration of how varying weights and impacts influence final scores
